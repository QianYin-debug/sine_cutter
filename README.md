# sine_cutter

基于 FFT 的音频正弦波（纯音调）自动检测与切割工具。

用 ffmpeg 流式解码音频，逐帧做频谱分析，自动找出其中**频率稳定、信噪比高**的纯音片段，并将其切割成独立的 16-bit WAV 文件，同时输出 `segments.csv` 时间清单。

---

## 适用场景

从长录音中自动定位并截取以下**稳定单频信号**的起止时间：

- 电话拨号音 / DTMF 音
- 设备提示音、蜂鸣声
- 测试音、校准音
- 电报 / 莫尔斯电码音
- 仪器、告警器的持续单频鸣响

**不适用场景**：带复杂谐波的音乐、语音、噪声类信号——这类信号的频谱峰值不集中、频率不稳定，会被判定为非正弦。

## 工作流程

1. **解码**：用 ffmpeg 将输入音频重采样为单声道、指定采样率的 PCM 流（`s16le`），边解码边分析，不占用额外磁盘空间。
2. **分帧 FFT**：按 `--block` 帧长、`--hop` 步进滑动，加汉宁窗后做 FFT（`--zp` 倍零填充提高频率分辨率）。
3. **峰值检测**：在 `--fmin` ~ `--fmax` 频段内找频谱峰值，取峰值邻域外的中位数作为背景噪声，计算 SNR。
4. **双门限判定**：同时满足
   - **频率稳定性**：连续 `--track` 帧的峰值频率波动不超过 `--ftol` Hz；
   - **信噪比**：当前帧 SNR > `--snr`，且连续 `--track` 帧的 SNR 均不低于 `--weak`（弱信号放宽通道）；
   - 另外要求峰值绝对幅度高于 `--floor`，且峰值不在频段边缘。

   连续多帧稳定才确认，避免瞬态误触发。
5. **片段合并**：把命中的连续帧合并成片段，间隔小于 `--gap` 秒的相邻片段二次合并，丢弃短于 `--minlen` 的片段。
6. **输出**：前后各留 `--pad` 秒余量，用 ffmpeg 精确切割为 WAV，并写 `segments.csv`。

---

## 用法

```bash
python3 sine_cutter.py input.wav                  # 检测并切割
python3 sine_cutter.py input.wav --no-cut         # 只生成 segments.csv，不切割
python3 sine_cutter.py input.wav -o output_dir    # 指定输出目录
python3 sine_cutter.py input.wav --fmin 300 --fmax 800 --track 20   # 自定义参数
```

---

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `input` | — | 输入音频文件（位置参数，必填） |
| `-o` / `--outdir` | `sine_clips` | 输出目录 |
| `--sr` | `8000` | 重采样率（Hz）。需满足 `--fmax <= sr/2` |
| `--block` | `4096` | FFT 帧长（样本数） |
| `--hop` | `512` | 帧步进（样本数），必须 ≤ `--block`。越小检测越精细、越慢 |
| `--zp` | `2` | 零填充倍数，实际 FFT 长度 = `block * zp` |
| `--fmin` / `--fmax` | `100` / `3500` | 检测频段（Hz） |
| `--snr` | `12.0` | 判定为正弦所需的信噪比（dB） |
| `--weak` | `4.0` | 弱信号允许的最低 SNR（dB），用于连续帧的一致性检查 |
| `--floor` | `-95.0` | 峰值绝对幅度门限（dB），低于此值视为无信号 |
| `--silence` | `0.00001` | 静音 RMS 门限，低于此值该帧不参与检测（会重置连续计数） |
| `--track` | `14` | 连续稳定帧数。越大越抗噪，也越迟钝、起点判定越滞后 |
| `--breakf` | `4` | 允许中断的帧数，间隔 ≤ 此值的命中帧仍算同一片段 |
| `--ftol` | `3.0` | 频率稳定容差（Hz） |
| `--gap` | `0.5` | 间隔小于该值（秒）的相邻片段合并 |
| `--minlen` | `0.1` | 最短片段时长（秒），短于此丢弃 |
| `--pad` | `0.5` | 每个片段前后保留余量（秒） |
| `--no-cut` | 关闭 | 只生成 `segments.csv`，不切割 WAV |

> **注意**：部分文档写 `--gap` 默认为 `5.0`，但程序实际默认值为 `0.5`。`5.0` 会把间隔 5 秒内的片段全部连成一段，调参时请以代码默认值为准。

---

## 输出

输出到 `-o` 指定的目录（默认 `sine_clips/`）：

- **`clip_XXXX_开始时间_结束时间.wav`**：每个检测到的纯音片段，16-bit PCM WAV。
- **`segments.csv`**：片段清单，表头如下

  ```
  index,start,end,start_sec,end_sec,duration_sec
  0001,00:00:00.492,00:00:02.452,0.492,2.452,1.960
  ```

运行示例：

```
duration: 00:00:08.000
segments: 2
[1/2] 00:00:00.492 -> clip_0001_00000.49_00002.45.wav
[2/2] 00:00:03.500 -> clip_0002_00003.50_00005.46.wav
saved clips: 2
```

## 调参指南

| 症状 | 调整方向 |
|---|---|
| 漏检、检测不到 | 降低 `--snr`（如 12 → 8）；减小 `--track`；缩小 `--fmin`/`--fmax` 到目标频段 |
| 误检、切出杂音 | 提高 `--snr`；增大 `--track`；收紧 `--ftol`（如 3.0 → 1.5）；提高 `--floor` |
| 片段被切成碎块 | 增大 `--gap`；增大 `--breakf` |
| 片段被连成一大段 | 减小 `--gap` |
| 起止时间不准 | `--track` 越大起点判定越滞后；先用 `--no-cut` 看 `segments.csv` 再定 `--pad` |
| 检测速度慢 | 减小 `--block`、增大 `--hop`、降低 `--sr` |
| 频率分辨率不够 | 增大 `--block` 或 `--zp` |

**建议流程**：先跑 `--no-cut` 看 `segments.csv` 的时间是否合理，参数满意后再去掉 `--no-cut` 正式切割。

## 已知限制

- 只识别**单频稳定**信号，对谐波丰富的音乐/语音无效。
- 检测到的起点存在固有滞后：需连续 `--track` 帧确认，因此真实起点前会有约 `(track-1) * hop / sr` 秒的回退修正，误差在帧级（默认约 0.06 秒/帧的量级），`--pad` 可用于补偿。
- `--silence` 判定为静音的帧会重置连续稳定计数，底噪持续高于该门限时该分支基本不触发。
- 依赖 ffmpeg 可解码输入格式；ffmpeg 非零退出时结果可能被截断（程序会打印警告）。
